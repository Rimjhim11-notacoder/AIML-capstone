L2: GUESS THE FARE AND FEEL THE METRICS
======================================

Task: Part A - Commit Fare Guesses
Description: Recorded fare estimates and reasons for five trips before
comparing them with the shared actual fares.
Command used: None. This was completed manually in the lab table.
Result: Guesses were recorded for trips A through E.

Task: Part B - Calculate the Shared Errors
Description: Calculated signed error (prediction minus actual), absolute error,
squared error, mean signed error, MAE, MSE, and RMSE for five trips.
Command used: The project metric helpers were used to verify the hand
calculation:

@'
import numpy as np
from src.models.common import mae, rmse

actual = np.array([10, 15, 20, 30, 25], dtype=float)
predicted = np.array([12, 13, 22, 40, 23], dtype=float)
print("MAE:", mae(actual, predicted))
print("RMSE:", rmse(actual, predicted))
'@ | .\.venv\Scripts\python.exe -

Result: MAE = $3.60; RMSE is approximately $4.82.

Task: Part C - Interpret the Baseline
Description: Explained that signed errors can cancel, MAE is the average
absolute dollar error, and RMSE weights large misses more heavily. Identified
Trip D as the largest contributor to RMSE and noted the need for subgroup checks.
Command used: None. This was a written interpretation of Part B.

Task: Part D - Extreme-Miss Comparison
Description: Changed only Trip D's prediction from $40 to $60 and recalculated
the metrics to show the effect of a larger miss.
Command used: Re-ran the Part B verification code with the prediction array
changed to [12, 13, 22, 60, 23].
Result: MAE = $7.60; RMSE is approximately $13.53. Trip D's signed error is
$30, absolute error is $30, and squared error is 900.

Task: Exit Ticket
Description: Summarized error cancellation, MAE, RMSE, and the need to report
units, sample size, and relevant context.
Command used: None. This was completed in writing.
